# Advent of Code

My [Advent of Code](https://adventofcode.com) solutions, grouped by language. I often use AoC as a trial run for a new language.

Each language lives in its own top-level directory (`go/`, `rust/`, `kotlin/`, ...), with its own README for building and running it.

## History

This repository is a collapse of earlier work. It started life as the Go repo for Advent of Code 2023, and the Rust solutions that used to live in [`advent-of-code-rs`](https://github.com/thomastickle/advent-of-code-rs) were folded in alongside it. Each language was brought over with its full history, with the original authors, dates and commit messages preserved, and merged into `master` (so commit hashes differ from the old repos). The `go` and `rust` branches are kept as the per-language histories.

New languages are developed on their own branch first, such as `typescript`, and merged here when they are ready.

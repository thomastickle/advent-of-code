# Puzzle inputs

Your personal Advent of Code inputs go here. Nothing in this directory is committed (see `.gitignore`), because AoC asks that inputs not be shared.

```
inputs/<year>/dayNN.txt     e.g. inputs/2015/day01.txt
```

Save each input from `https://adventofcode.com/<year>/day/<n>/input`.

To keep them somewhere else, set `AOC_INPUTS_DIR` to an absolute path with the same layout.
